============================================================
 VEERABHADRA RICE DISTRIBUTORS — WEBSITE SETUP
============================================================

TO ADD YOUR LOGO:
-----------------
1. Right-click the logo image (the circular gold Veerabhadra logo)
2. Save it as:  logo.png
3. Place it in THIS folder:
   veerabhadra-website\logo.png

The website already references "logo.png" — once you place the 
file here, the logo will automatically appear:
  ✅ In the navbar (top left, small circular)
  ✅ In the hero section (large, centered, glowing)
  ✅ In the footer (bottom left)

TO OPEN THE WEBSITE:
--------------------
Double-click index.html  OR  open it in any browser.

FILES IN THIS FOLDER:
---------------------
  index.html  — main website
  style.css   — all styling
  script.js   — animations & interactions
  logo.png    — YOUR LOGO (place here)
  README.txt  — this file
